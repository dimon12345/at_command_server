Сервер AT команд
================

Приложение эмулирует модем с поддержкой AT команд.

Поддерживаемые команды:
AT+CPIN="4321" - разблокировка
AT+CPIN? - статус блокировки SIM карты PIN кодом
AT+COPS? - статус подключения к оператору
AT+COPS= - команды выбора подключения к оператору

Поддерживается словарь ожиданий с шаблонами:
ATI - информация об устройстве
ATD* и ATL. - шаблонные ответы из dictionary.txt

После сборки и запуска выводится имя tty устройства. Для подчключения можно использовать 
команду "screen /dev/ttys0005"
